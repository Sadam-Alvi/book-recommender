# Book Recommender System

An intelligent book recommendation engine built with machine learning that suggests similar books based on semantic similarity. Users browse their book collection and instantly get personalized recommendations powered by AI.

## 📖 Project Overview

This project combines natural language processing and web technology to create a user-friendly book discovery platform. It analyzes book metadata (title, description, genre, author) and finds books with similar characteristics using advanced embedding models.

### Key Capabilities
- **Semantic Search**: Uses AI embeddings to understand book meaning, not just keywords
- **Fast Recommendations**: Pre-computed similarity matrix enables instant results
- **Visual Display**: Shows book covers, authors, and details in an intuitive grid layout
- **Six Recommendations**: Returns top-6 most similar books for each selection

## 🚀 How It Works

### The Recommendation Pipeline

1. **Data Preparation** (`app.ipynb`)
   - Load book metadata from CSV
   - Clean and preprocess text (titles, descriptions, genres, authors)
   - Combine multiple features into a unified "tags" field

2. **Text Embedding** (`app.ipynb`)
   - Convert text into numerical vectors using **BGE-Small-EN-v1.5** model
   - Each book becomes a 384-dimensional semantic representation
   - Similar books naturally cluster close together in vector space

3. **Similarity Computation** (`app.ipynb`)
   - Calculate cosine similarity between all books
   - Creates a matrix where each cell represents how similar two books are
   - Scores range from -1 to 1 (higher = more similar)

4. **Real-Time Serving** (`display.py`)
   - User selects a book via dropdown
   - App looks up pre-computed similarity scores
   - Returns and displays top-6 matches with covers and details

## ⚡ Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Generate Recommendation Model
Run the Jupyter notebook to create the similarity matrix:
```bash
jupyter notebook app.ipynb
```
This generates two files:
- `similarity_matrix.pkl` – Pre-computed similarity scores
- `count_vectorizer.pkl` – Embedding model

### 3. Run the Web App
```bash
streamlit run display.py
```

The app opens in your browser at `http://localhost:8501`

## 🔧 Technical Details

### Vectorization: 
- Convert data into vector
- Trained on semantic textual similarity tasks
- Optimized for fast inference with high accuracy
- Understands context beyond simple keyword matching

### Cosine Similarity
Measures similarity between book vectors using:
```
Similarity = (A · B) / (‖A‖ ‖B‖)
```
- **1.0** = Identical books
- **0.5** = Moderately similar
- **0.0** = No similarity
- **-1.0** = Opposite characteristics

### Performance
- Recommendations generated in <100ms per query
- Handles 100s-1000s of books efficiently
- Pre-computation trades storage for speed

## ⚠️ Troubleshooting

| Issue | Solution |
|-------|----------|
| `similarity_matrix.pkl` not found | Run `app.ipynb` to generate it |
| `count_vectorizer.pkl` not found | Run `app.ipynb` to generate it |
| No books appear in dropdown | Verify `Book_Details.csv` exists and has data |
| Book covers don't load | Check that `cover_image_uri` contains valid URLs |
| App runs slowly | Ensure similarity matrix is cached; check file size |
| Recommendations seem irrelevant | Verify book descriptions are complete in CSV |

## 📝 Notes

- The first app run downloads the embedding model (~100MB) – subsequent runs use cache
- Similarity matrix is reusable across app restarts
- Adding new books requires regenerating the similarity matrix
- The `count_vectorizer.pkl` stores the embedding model for reproducibility
